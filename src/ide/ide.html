Salesforce OrgStudio

A lightweight in-browser IDE for Salesforce.

One click connects to the Salesforce org you're already logged into (reuses that tab's session).

  • Ctrl/Cmd + S — Save / deploy the active file
  • Ctrl/Cmd + F — Find in the active file
  • Ctrl/Cmd + Enter — Run anonymous Apex
